## Thesis Implications

### ⚠️ Floor Detected: Fundamental Limit at ~1.3623/step

The persistent regret floor suggests one or more of:

1. **Credit assignment ambiguity**: With N=3 overlapping paths, the
   residual decomposition cannot perfectly isolate per-UAV contributions.
   Multiple faults on the same path create a rank-deficiency problem.

2. **Topology aliasing**: Fresh random topology each epoch means the agent
   can never fully memorize path-fault correlations — identifiability is
   fundamentally limited.

3. **Exploration-exploitation trade-off**: With epoch_decay=1.0 and finite T,
   the UCB bonus may not drive sufficient exploration to eliminate uncertainty.

4. **SA approximation gap**: The SA solver (approximate QUBO minimizer) may
   not always find the true QUBO optimum, creating a systematic gap.

**For the thesis:** This floor is actually *interesting* — it establishes a
lower bound on the information-theoretic difficulty of the problem. The key
insight is that a *quantum* annealer (as opposed to SA) could reduce the
floor by more reliably solving the QUBO, closing the solver gap.

**Recommended action:**
- Investigate if floor is algorithmic (credit assignment) or solver-induced
- Compare with Oracle agent (SA but true θ*/φ*) floor
- If Oracle also has a floor → problem is in the solver
- If Oracle → 0 but QA-MAB floors → problem is in learning

## Key Question: Does learning achieve optimal routing?

**Partially.** QA-MAB reduces regret significantly from P=5 to P=50,
but retains a floor of ~1.3623/step. The agent learns, but does
not fully close the gap with the omniscient optimal.

This motivates quantum advantage: a true quantum annealer solves the QUBO
to higher accuracy (fewer annealing errors), which could reduce or eliminate
the floor.
